# Transition Phase Task Template

```markdown
Read and follow completely:

https://raw.githubusercontent.com/danso0429/patch-verification-governance/main/LLM-ENTRYPOINT.md

Task:

Implement or review Phase [N] only.

Additional constraints:

- Do not begin later phases.
- Do not advance `CURRENT-STATUS.yaml` automatically.
- Keep the current canonical gate and fallback unchanged unless explicitly
  authorized by both status and user instruction.
- Before editing, report the exact governance and implementation commits, current
  phase, scope, prohibited work, files, tests, receipts, and rollback boundary.
- At completion, provide the phase checklist and a proposed status update for
  separate user approval.
```
